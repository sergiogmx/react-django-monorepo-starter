# 0003. Auth0 for authentication

- Status: accepted
- Date: 2026-11-18

## Context

Almost every feature needs to know who the user is. Building sign up,
login, password reset, email verification and token refresh in-house is a
lot of security-sensitive code that is not the product.

## Decision

- Users log in through **Auth0 Universal Login** (Authorization Code +
  PKCE) using `@auth0/auth0-react`. The API is registered in Auth0 as its
  own audience.
- The API validates Auth0 access tokens itself with PyJWT: RS256 only,
  issuer and audience checked, keys fetched from the tenant's JWKS and
  cached. Validation lives in `infrastructure/auth`; `domain` and
  `application` only see an `Identity` (`subject`, `email`).
- Every DRF view is protected by default. Public views opt out explicitly.
- The API keeps a local `UserProfile` per Auth0 `sub`, created on first
  use. It never stores passwords. `django.contrib.auth` remains only for
  Django Admin.
- The web app hides the SDK behind its own `AuthContext` / `useAuth()`.
- Tokens are cached in **local storage with rotating refresh tokens**.

## Consequences

- No credential handling in our code; password reset, sign-up and MFA are
  Auth0 settings.
- Local development needs an Auth0 tenant. Without one, the project still
  runs: protected endpoints answer 401 and the web app shows a notice.
- Tests never call Auth0: they sign tokens with a locally generated RSA key.
- **Local storage trade-off**: tokens there are readable by any script
  injected through an XSS bug. We accept it because, without a custom Auth0
  domain, the alternative (in-memory cache + silent authentication) breaks
  on every reload in Safari and Brave, which block the third-party cookie
  it relies on. Mitigations: short-lived access tokens and refresh-token
  rotation. **For production with a custom domain, switch
  `cacheLocation` to `memory`** in `apps/web/src/auth/AuthProvider.tsx`.
- Changing provider later means replacing `infrastructure/auth` and
  `AuthProvider.tsx`; use cases, views and components stay as they are.
